# 残っていること

35ツールはすべて実装済みだが、「動くもの」と「出せるもの」の間にはまだ距離がある。
ここに **終わっていないものを全部** 書く。理由と、なぜ後回しにしたかも残す。

最終更新: 2026-08-15

---

## 1. 最優先: 実機で一度も動かしていない

**このアプリは実機で検証されていない。** 開発環境のエミュレータが起動せず
（`avd-medium-phone-api-36` は AEHD が有効でも adb が offline のまま）、
JVM テスト383件とビルドの成功だけで進めてきた。

つまり以下は「書いたが動くか分からない」状態にある。

| 対象 | 何が確認できていないか | 危険度 |
|---|---|---|
| **バックアップの復元** | DB ファイルを差し替える破壊的操作。一度も実行していない | **高** |
| **スイープ測定**（ディレイ/極性/残響） | 再生と録音の同時実行、AudioTimestamp による時刻合わせ | **高** |
| **R8 で難読化したリリースビルド** | Room / Hilt / Navigation が難読化後に壊れていないか | **高** |
| 録音 | 長時間録音、ストレージ逼迫時の挙動 | 中 |
| **本番モードの通知オフ** | おやすみモードの許可取得〜切り替え〜復帰の一巡。**端末を黙らせたまま戻し忘れる**のが最悪の失敗 | **高** |
| **SE パッド** | 取り込み（SAF）、mp3/m4a の再生、同時発音、音声フォーカスの奪い合い | 中 |
| Room v7→v8 | sound_cues 追加の AutoMigration。既存データを持つ端末でしか起きない | 中 |
| SPL の絶対精度 | 基準となる騒音計との突き合わせ（プランの完了条件は ±2dB） | 中 |
| 各画面の描画 | レイアウト崩れ、暗所/屋外テーマでの視認性 | 低 |

**やること**: 実機に入れて全画面を一巡する。特に復元は
**捨ててよいデータで試す**こと。

## 2. フォアグラウンドサービスが無い（録音が途中で止まる）

Android 9 以降、アプリがバックグラウンドに回るとマイクへのアクセスが止まる。
現在フォアグラウンドサービスを実装していないので、

- 録音中に他のアプリへ切り替えると **録音が止まる**
- SPLロガーで記録している最中に画面を離れると **記録が途切れる**

`KeepScreenOn` を入れてあるので画面が点いている限りは持つが、
**現場で長時間まわす道具としては不十分**。

**やること**:
- `FOREGROUND_SERVICE` と `FOREGROUND_SERVICE_MICROPHONE` の権限を
  `core:audio` のマニフェストに追加
- 録音・SPLロガー用のフォアグラウンドサービスを実装（通知に経過時間とレベルを出す）
- Android 14 以降は `foregroundServiceType="microphone"` の宣言が必須
- Play の Data safety と権限の説明も更新が要る

これは Phase 5 の課金より先に片付けたほうがよい。**機能そのものの信頼性の問題**なので。

## 4. テストが足りていないところ

### 計装テスト（androidTest）が1つも無い

JVM テストは383件あるが、**実機/エミュレータ上で走るテストはゼロ**。
そのため以下が検証されていない。

- **Room のマイグレーション**。スキーマは `core/database/schemas/` に
  1〜7 まで committed されているが、`MigrationTestHelper` によるテストが無い。
  **マイグレーションの失敗は「既存データを持つ利用者の端末でだけ」起きる**ので、
  開発中は一切気づけない。ここは優先度が高い
- 画面の表示と操作（Compose UI テスト）
- 実際の AudioRecord / AudioTrack を使った録音・再生

**やること**: まず Room のマイグレーションテストを入れる。
`androidTestImplementation(libs.androidx.room.testing)` を足して、
v1 から順に v7 まで開けることを確認する。

### 数値まわりで未検証のもの

- SPL の絶対値（基準騒音計との比較）
- 残響時間の実測値（既知の残響時間を持つ部屋との比較）。
  合成データでは検証済みだが、実際の部屋では未確認
- 混変調の計算結果と、実際に干渉が起きるかの突き合わせ

## 5. 意図的に実装していないもの

「できなかった」ではなく「**やらないと決めた**」もの。理由も残す。

| 項目 | 理由 |
|---|---|
| **ワイヤレスの周波数割り当てデータベース** | 総務省の一次資料で現行の割り当てを確認できなかった（ポータルが自動取得を403で拒否、PDFはテキスト抽出不可、検索で拾えるのは2019年の移行前の資料）。記憶で書くと「アプリが使えると言ったから使った」で違法運用になる。混変調計算のみ実装 |
| **自動のクラウド同期** | 認証の実装に加えて「データを端末外に送信する」というプライバシーポリシーの記載が必要になる。ファイルに書き出して利用者が自分のクラウドに置く形なら、「端末外に一切送らない」性質を保てる |
| **卓の機種固有スナップショット** | 内部データは機種ごとに形式が違い、外から読める保証もない。対応卓の外では何の役にも立たなくなるので、人が読める記録にした |
| **単発反射の自動検出**（IR測定） | 拡散した残響から離散反射だけを機械的に切り分けるのは部屋によって外れが大きい。外して「壁まで何m」と断定すると現場を誤らせる。包絡を描いて読んでもらう方式にした |
| **ディレイ実測の絶対値** | 端末の入出力遅延が数十ms乗り、量が端末ごとに違ってアプリからは測りきれない。基準との差を出す形にした（同じ端末の遅れは引き算で消える） |

これらを将来やるなら、**判断の前提が変わったことを確認してから**にすること。

## 6. 作りとして粗いところ

### 日本語しかない

文字列はすべて `values/strings.xml` に日本語で直接書いてある。
`values-ja/` に分けていないので、**英語圏の端末でも日本語が出る**。

海外に出す予定が無いなら現状で問題ないが、出すなら
`values/` を英語にして `values-ja/` を作る作業が発生する（全モジュール）。

### アクセシビリティを見ていない

- `contentDescription` を設定していない要素がある（アイコンボタン、グラフ）
- TalkBack で操作できるか未確認
- 文字サイズを最大にしたときのレイアウト崩れ未確認

現場向けの道具として **タップ領域 48dp 以上** は守っているが、
スクリーンリーダー対応は手つかず。

### ランチャーアイコンが暫定

アダプティブアイコンの形にはなっているが、中身は仮のベクター。
Play に出すなら作り直しが要る（512×512 のストアアイコンも別途必要）。

### lint 警告が11件残っている

エラーは0だが警告が残っている。実害は無いが、放置すると
本当に見るべき警告が埋もれる。

| 警告 | 件数 | 内容 |
|---|---|---|
| `EmptySuperCall` | 8 | ViewModel の `onCleared()` 内の不要な `super` 呼び出し |
| `TypographyFractions` | 2 | `1/3` などを分数記号にすべきという指摘。**RTA の「1/3 oct」は意図的にこの表記**なので抑制でよい |
| `AutoboxingStateCreation` | 1 | `mutableStateOf(0)` を `mutableIntStateOf` にできる |

## 7. ツールごとの積み残し

| ツール | 残っていること |
|---|---|
| SPLロガー | バンド別データを保存していない（3時間×31バンドは重いため）。必要になったらBLOBで別テーブル |
| 録音 | フォアグラウンドサービス（上記2）。保存期間の自動削除も無い |
| ステージプロット | 拡大縮小ができない。記号の回転もできない |
| 機材台帳 | バーコード/QR 未対応。持ち出し先（どの案件に出ているか）を記録できない |
| 見積・請求 | 請求書番号の自動採番が無い（手入力）。稼働記録から明細を起こす連携も無い |
| 稼働記録 | 月別の集計画面が無い（全件の合計のみ）。案件との紐付けも未実装 |
| スナップショット | 写真を添付できない。パッチ表からCH名を引き継げない |
| バックアップ | 自動実行が無い。復元後にプロセスを自分で終了させる必要がある（案内は出す） |
| 案件管理 | 各ツールから案件を選ぶ導線が弱い。`jobId` を持つモデルは多いが UI で結び付けていない |

**案件との紐付けは全体に効く**。データモデル側は `jobId` を持たせてあるので、
「案件を開くと関連する記録・書類が全部並ぶ」形にすると道具としての性格が変わる。
